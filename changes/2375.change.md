- [change][experimental] Move the DyOHM day latch (`new_day`, `dt_since_start_prev`) from `SUEWS_TIMER` into `OHM_STATE`, so the midnight coefficient update survives any entry point that returns the model state, including `SUEWS_cal_Main`, which runs on a local timer copy. The physics no longer writes the timer, the per-iteration save and restore of the two timer fields is replaced by the existing `OHM_STATE` reset, and model output is unchanged. Bridge schema versions move with it: timer 1 -> 2 (16 values), `OhmState` 3 -> 4, error entry 1 -> 2, and restart checkpoint 2 -> 3, whose timer now carries only `dt_since_start` and `tstep`. Checkpoints written with schema version 2 are rejected with a message asking for the preceding segment to be rerun (#2333, #2375).
