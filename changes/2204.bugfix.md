- [bugfix] Rejected the unimplemented `model.physics.roughness_length_momentum` code 5 (`ALTERNATIVE`) at validation and guarded unsupported momentum roughness methods in the Fortran kernel (#2105)
  - `SUEWS_cal_RoughnessParameters` had no branch for `RoughLenMomMethod = 5`, leaving `z0m_zh` and `zdm_zh` unassigned on grids with roughness elements (`Zh > 0`). `ModelPhysics` now refuses code 5 on validated construction and direct assignment (numeric, enum, `RefValue` and readable-name `"alternative"` forms) with a message naming the implemented methods 1-4, and the kernel raises fatal error code 113 for any unsupported `RoughLenMomMethod` (including on `Zh == 0` grids) while keeping methods 1-4 bit-identical.
