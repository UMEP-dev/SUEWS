- [bugfix] Schema `2026.6.dev16` reports non-finite initial vegetation senescence degree days (`sdd_id`) during configuration, migration and Python model handoff. Previously these could reach the model as zero. An omitted value defaults to zero and signed finite values retain their references. See the [migration guide](https://docs.suews.io/latest/inputs/transition_guide.html#schema-dev16-vegetation-senescence) (#2001).
